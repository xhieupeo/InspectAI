# InspectAI

AI-powered Industrial Visual Quality Inspection System.

## Overview

InspectAI is a computer vision-based system designed to detect visual anomalies in electronic components and generate structured inspection reports.

## Project Goals

- Computer Vision and Visual Anomaly Detection
- Model Training and Evaluation
- Harness Engineering
- Retrieval-Augmented Generation (RAG)
- AI Agent Development
- End-to-end AI Engineering

## Tech Stack

- Python
- NumPy
- OpenCV
- PyTorch
- Anomalib
- DINOv2
- LangGraph
- FastAPI

## Project Structure

- `src/`: Main source code
- `data/`: Dataset directory
- `tests/`: Automated tests
- `docs/`: Project documentation

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd InspectAI
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate environment (Windows PowerShell)

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```
